Especificação v2.0

TokLang v2 — Compilador de Contexto

O TokLang v2 é um compilador determinístico de contexto para LLMs que executa 100% offline (p95 de 6,35 ms em Node.js), com contagem BPE real via js-tiktoken (o200k_base e cl100k_base) e paridade completa no SDK Python.

Mudança fundamental da v2: Abreviações consonantais e chamadas a LLM externo para comprimir foram abolidas. Toda transformação agora é determinística, auditável e submetida à guarda estrita de monotonicidade BPE.

Codec Estrutural Lossless (@table e @struct)

Arrays JSON uniformes retornados por APIs, bancos de dados ou servidores MCP desperdiçam até 60% dos tokens BPE repetindo nomes de chaves, aspas e delimitadores. O codec v2 eleva o schema uma única vez:

// Entrada JSON (1.610 tokens o200k_base para 25 usuários) { "users": [{ "id": 1001, "name": "Engineer_1", "role": "staff", "active": true }] } // Saída TokLang v2 (645 tokens o200k_base, -59.9%, 100% reversível via decodeStructured) @table users[25]{id,name,role,active}: 1001|Engineer_1|staff|true

Strings contendo caracteres reservados (|, quebras de linha, espaços nas pontas ou literais como "true" e "123") são serializadas automaticamente com escape JSON, garantindo roundtrip bit-a-bit idêntico.

CAPC: Cache-Aware Prompt Compression

Compressão dinâmica aplicada cegamente sobre todo o prompt invalida o Prompt Caching de provedores como Anthropic, OpenAI e Gemini. O TokLang v2 implementa CAPC de dois níveis via compileMessages():

CamadaConteúdoTratamento TokLang v2Efeito no Cache
Tier 0 (Static) System prompts, schemas, regras fixas Compressão estritamente query-agnostic (lossless) + SHA-256 Prefixo 100% imutável entre turnos + cache_control
Tier 2 (Dynamic) Tool outputs JSON, RAG, histórico, user Codec @table + deduplicação + BM25 query-aware Corte imediato em tokens não-cacheados (100% do preço cheio)

Invariantes Formais de Segurança

  • BPE Monotonicity Guard: Se uma transformação não reduzir tokens BPE reais (tokensAfter > tokensBefore), o compilador executa rollback automático para o segmento original.
  • Polarity & Negation Lock: Palavras de negação e restrição (não, sem, nunca, jamais, exceto, not, never, without, only, !=, <=) nunca entram em listas de stopwords.
  • Proteção Atômica de Código: Blocos ```...```, código inline e consultas SQL/DDL são isolados antes de qualquer poda discursiva.

SDK JavaScript & Python

JavaScript / Node.js

const { TokLang, TokLangMiddleware } = require('toklang'); const compiler = new TokLang(); const report = compiler.compile(payloadOrRag, { mode: 'balanced', query: 'quorum Raft', maxTokens: 220, encoding: 'o200k_base' }); // Middleware CAPC transparente para OpenAI / Anthropic const client = new TokLangMiddleware({ target: 'anthropic', apiKey: process.env.ANTHROPIC_API_KEY });

Python 3.10+

from toklang import compile_prompt, compile_messages, decode_structured report = compile_prompt(payload, mode="lossless") restored = decode_structured(report["text"]) capc = compile_messages(messages, provider="anthropic", mode="balanced") print(capc["cache"]["prefix_hash"], capc["economics"])
