# TokLang VS Code Extension

Esta extensão fornece suporte e compressão para a sintaxe **TokLang**.

## Recursos

- **Realce de Sintaxe:** Suporte a arquivos `.tok` destacando comandos, parâmetros e modificadores.
- **Compressão de Seleção:** Clique com o botão direito no texto selecionado e escolha `TokLang: Comprimir Prompt` para compilar o texto selecionado inline.

## Instalação

1. Baixe o arquivo `.vsix` gerado.
2. No VS Code, acesse o menu de Extensões (`Ctrl+Shift+X`).
3. Clique nos três pontos (`...`) no canto superior direito e selecione `Install from VSIX...`.
