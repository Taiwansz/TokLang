Perguntas
frequentes.

Preciso mudar como escrevo meus prompts? +
Não. Esse é o ponto central do TokLang — você escreve exatamente como sempre escreveu. O motor de compressão opera em segundo plano e é completamente invisível.
Funciona com qualquer modelo de IA? +
Sim. TokLang é agnóstico ao modelo. Funciona com OpenAI, Anthropic Claude, Google Gemini, Mistral, ou qualquer modelo via API. A compressão acontece antes da chamada.
A qualidade das respostas cai? +
Não. O TokLang comprime sem perder intenção semântica. O modelo recebe um prompt limpo e completo — apenas sem verbosidade desnecessária. Em muitos casos a resposta melhora por ser mais precisa.
Como é calculada a economia de tokens? +
Comparamos o token count do prompt original com o prompt comprimido antes de enviar ao modelo. O dashboard mostra em tempo real quanto você economizou em tokens e em dólares.
Meus prompts ficam armazenados? +
No plano Starter, os prompts são processados e descartados. Nos planos Pro e Team você pode ativar analytics histórico, sempre com opt-in explícito e dados criptografados em repouso.

TokLang

TokLang é um middleware de compressão de prompts que atua como intermediário invisível entre o usuário e qualquer modelo de linguagem. Você escreve normalmente; ele comprime automaticamente.

A economia típica é de 65–85% em tokens, sem nenhuma mudança na qualidade da resposta do modelo.

Princípio central: O usuário nunca vê ou toca na notação TokLang. Ela opera completamente em segundo plano.

Quickstart

Instale o SDK e faça sua primeira compressão em menos de 5 minutos:

# instalar
npm install toklang

# uso básico
import { compress } from 'toklang'

const result = await compress("Bom dia! Pode fazer uma API em Node?")
// → "cr $js #api"

console.log(result.compressed) // cr $js #api
console.log(result.savings) // 0.71 (71%)

Para integrar como middleware transparente no seu pipeline:

import { TokLangMiddleware } from 'toklang'

const client = new TokLangMiddleware({
  target: 'openai', // ou 'anthropic' | 'gemini'
  apiKey: process.env.OPENAI_KEY,
  tokLangKey: process.env.TOKLANG_KEY
})

// use exatamente como o SDK original
const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: userMessage }]
})

Como funciona

O pipeline completo tem quatro etapas:

1. INPUT → prompt natural do usuário
2. COMPRESS → motor TokLang → notação comprimida
3. EXPAND → expansor → linguagem natural limpa
4. OUTPUT → enviado ao modelo de destino

A etapa 3 garante que o modelo nunca receba a notação TokLang — apenas um prompt limpo e preciso em linguagem natural.

Sintaxe

A gramática TokLang segue um formato posicional com separadores por ponto-e-vírgula:

AÇÃO $LANG @FRAMEWORK #ESTRUTURA; tarefa; in[params]; modificadores

Apenas a AÇÃO é obrigatória. Todos os demais campos são opcionais e posicionais.

Separador ; divide os blocos lógicos do prompt. A ordem importa: ação+contexto técnico → tarefa → parâmetros → modificadores.

Ações

O primeiro token do prompt define a ação. Sempre em letras minúsculas.

Token Expande para Uso
cr Crie / Faça Criar código, componentes, arquivos
fix Corrija / Resolva o bug em Debug e correção de erros
ex Explique / Ensine Explicações e tutoriais
rf Refatore Melhorar código existente
op Otimize Performance e eficiência
tst Escreva testes para Unit tests, integration tests
doc Documente JSDoc, docstrings, README
cv Converta / Porte Migração entre linguagens ou formatos
rev Revise / Faça code review de Review de código
sum Resuma Resumir texto ou código

Modificadores

Ajustam a qualidade, estilo ou requisitos da resposta.

Token Significado
ui+ Interface visualmente agradável / estilizada
prd Production-ready, boas práticas, robusto
cm Incluir comentários explicativos no código
dk Dar exemplos de uso práticos
typ Incluir tipagem / type hints / annotations
async Implementação assíncrona
min Versão mínima / simples / sem dependências extras
* Máxima qualidade — não economize esforço
in[a,b] Parâmetros de entrada / campos
out[x,y] Valores de saída esperados
err[404,500] Tratar esses códigos de erro especificamente

Cada chamada à API de compressão conta como uma compressão, independentemente do tamanho do prompt. Prompts comprimidos pelo SDK ou extensão do navegador também contam.
